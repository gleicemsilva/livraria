# Livraria Leia Mais
Projeto para o curso de Web Designer.

📚 Livraria Leia Mais

Site institucional desenvolvido para a Livraria Leia Mais, uma livraria localizada em Manaus/AM.

O projeto foi desenvolvido com foco em experiência do usuário, acessibilidade, responsividade e organização semântica do conteúdo.

🎯 Objetivo

Criar uma página web que apresente a livraria, seus livros em destaque e seus diferenciais, além de facilitar o contato com os clientes.

👤 Público-alvo

Jovens adultos e estudantes que gostam de literatura e utilizam principalmente dispositivos móveis para pesquisar e descobrir novos livros.

Persona

Júlia Martins, 21 anos, estudante universitária de Manaus. Gosta de romance, fantasia e ficção, acompanha recomendações de livros nas redes sociais e busca praticidade para encontrar sua próxima leitura.

🎨 Identidade visual

A identidade visual utiliza uma paleta de tons creme, marrom e verde-oliva, buscando transmitir uma sensação de acolhimento e tranquilidade.
Merriweather: títulos e elementos de destaque
Roboto: textos e informações gerais

🧩 Estrutura

O site é dividido nas seguintes seções:
Início: apresentação da livraria e chamada principal
Sobre: história e proposta da marca
Livros: catálogo com livros em destaque
Diferenciais: características e experiências oferecidas pela livraria
Contato: formulário e canais de atendimento

♿ Acessibilidade

Foram aplicados recursos de acessibilidade, como:
HTML semântico
Textos alternativos (alt) nas imagens
Label associado aos campos do formulário
Navegação com foco visível
Áreas de interação adequadas para links e botões
Uso de atributos ARIA quando necessário
Redução de animações com prefers-reduced-motion

📱 Responsividade

O layout foi desenvolvido para diferentes tamanhos de tela utilizando CSS Grid e Media Queries, adaptando a estrutura para desktop, tablet e dispositivos móveis.

🛠️ Tecnologias

HTML5
CSS3
Google Fonts
CSS Grid
Media Queries
